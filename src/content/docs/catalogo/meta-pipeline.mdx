## O que ele faz

Faz, em intervalos predefinidos (por padrão, a cada 5 minutos), uma cópia das informações do Meta e a disponibiliza por uma API protegida por chave de acesso. Os demais sistemas leem dessa cópia, em vez de cada um buscar os dados por conta própria. Com isso, a alimentação dos sistemas e planilhas passa a ter uma fonte única, e um sistema novo só precisa pedir o que a automação já traz.
