## Níveis de acesso

<div class="tabela-padrao">

| Nível | Perfil | O que pode fazer |
|---|---|---|
| **1. Usuário** | Opera o sistema no dia a dia. | Usar o sistema. |
| **2. Administrador funcional** | Administra o uso do sistema. | Gerenciar usuários e cadastros. |
| **3. Manutenção técnica** | Desenvolve e mantém. | Alterar código e configurações, em ambiente de teste (geralmente a máquina de quem desenvolve) quando aplicável. |
| **4. Administração de produção** | Responde pelo ambiente real. | Publicar mudanças e cuidar do servidor, das credenciais e dos backups. |

</div>

Ninguém **recebe todos os níveis** só por usar um sistema: cada pessoa tem o nível que o trabalho exige.

## Responsabilidades por sistema

Cada ficha do catálogo identifica quem pediu, quem usa e quem construiu e mantém o sistema, que é o responsável técnico. O proprietário institucional é sempre a Cooperacre.

O responsável técnico é uma só pessoa por sistema, designada formalmente. Quem vai construir ou alterar um sistema é indicado a ele, ou por ele.

## Contas

- Os sistemas usam uma **identidade institucional** (o e-mail de sistemas, `sistemascooperacre@gmail.com`) como proprietária dos serviços.
- Sempre que a plataforma permitir usuários individuais, cada pessoa usa **conta própria**, nunca uma senha compartilhada. Assim é possível saber quem fez cada alteração.
